# InCloseMail releases

Installers for [InCloseMail](https://inclosemail.com), the classic-Outlook-style desktop email and calendar client for Microsoft 365, by EmuKey LLC.

InCloseMail checks this repository for updates (Help → Check for Updates, and once a day if turned on in File → Options). Each release:

- is tagged with the app's calendar version, `YY.MM.DDNN` (for example `26.10.2005`: 20 October 2026, fifth build that day);
- carries `InCloseMail.msi` as an asset, signed by **EmuKey LLC**. The app installs an update only when the MSI's signature is valid and from that publisher.

The source code is not in this repository.
